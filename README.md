# BajuBesi Labs Red Cogs

Cogs for [Red-DiscordBot](https://github.com/Cog-Creators/Red-DiscordBot) 3.5, made for the BajuBesi Discord.

| Cog | What it does |
| --- | --- |
| **enshrouded** | Live status panel for an Enshrouded dedicated server: online state, player count, server news and admin controls. |
| **jukebox** | A Now Playing panel with buttons (pause, skip, seek, loop, shuffle, volume, filters, queue, like, autoplay) on top of Red's Audio cog. |

## Install

```
[p]load downloader
[p]repo add bajubesi https://github.com/fhazal/red-cogs
[p]cog install bajubesi jukebox
[p]load jukebox
```

`[p]` is your bot's prefix. **jukebox** needs Red's Audio cog (`[p]load audio`).

> [!NOTE]
> Both cogs were written for the BajuBesi server: some role, channel and emoji ids are set near the top of each file. Change them for your own server.
